# build_vertex_grid_assets.py

Build the low-resolution icosphere grid assets used by the whole vertex-wise
pipeline (see `others/README.md` for how the pieces fit together), from a
dHCP symmetric surface template.

Data-free port of `etape0_grille_dhcpsym_basse_resolution.py`. Equivalent
step: build an icosphere at a chosen density (642 / 2562 / 10242 / 40962
vertices per hemisphere, L and R vertex-matched via
`wb_command -surface-flip-lr`), then bring the template's 32k surface area
and sulcal-depth metrics onto it.

## Requirements

- Connectome Workbench (`wb_command`), a free tool from the Human
  Connectome Project -- not shipped here.
- A local copy of the dHCP symmetric surface template (week-40, publicly
  released by the developing Human Connectome Project) -- not shipped here
  either; `--template_dir` must point at your own copy.

Neither is data-free by nature (they are external tools/public assets, not
generated by this repo), but neither is study-specific: anyone can install
Workbench and download the template independently of any particular cohort.
`generate_example_native_surfaces.py` builds a fully synthetic stand-in
template (small, fabricated icospheres) so the resampling *code* can still
be smoke-tested without either.

## Options

| Option | Meaning |
| --- | --- |
| `--template_dir` | Directory with the dHCP symmetric template files. |
| `--wb_command` | Path to (or name of) the `wb_command` executable. |
| `--output_dir` | Where the grid assets are written (default `assets`). |
| `--n_vertices` | Vertices per hemisphere: 642 / 2562 / 10242 / 40962 (default 10242). |

## Outputs (in `--output_dir`)

```
sphere_hemi-{L,R}_dhcpSym_dens-{N}.surf.gii
area_hemi-{L,R}_dhcpSym_dens-32k.shape.gii
sulc_hemi-{L,R}_dhcpSym_dens-{N}.shape.gii
```

## Example

```bash
python build_vertex_grid_assets.py \
    --template_dir /path/to/dhcp-symmetric-template \
    --wb_command /Applications/ConnectomeWorkbench.app/Contents/usr/bin/wb_command \
    --output_dir assets --n_vertices 10242
```
